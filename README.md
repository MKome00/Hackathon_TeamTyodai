# アイデア

## ペットの生活をまとめて管理するアプリ

ペットごとにプロフィールを作成し、健康管理・予定・フードや用品の管理などを1つのアプリでまとめて行うサービス。

複数のペットを飼っている場合でも、ペットごとの情報を切り替えながら管理でき、家族全体で予定や健康状態を共有できる。

### 機能

#### 1. ペットごとのプロフィール管理
- 名前　✅
- 種類　✅
- 年齢　✅
- 体重　✅
- 写真　✅
- その他の基本情報　✅

複数匹を飼っている場合でも、ペットごとにプロフィールを作成して切り替えながら管理できる。　✅

#### 2. 健康・通院履歴の管理
- 体重　✅
- 予防接種　✅
- 健康診断　✅
- 通院履歴　✅
- 薬　✅

などを記録・確認できる。

#### 3. 予定・リマインド機能
以下のような予定を登録し、時期が近づいたら通知する。

- 予防接種　✅
- 健康診断　✅
- 薬
- トリミング　✅
- フードの補充
- その他の予定　✅

#### 4. フード・用品の在庫管理
フードやトイレ用品などの残量や消費ペースを管理する。

例：
- 「ポチのフードはあと10日分です」
- 「ココのフードはあと3日でなくなりそうです」
- 「トイレ用品の補充時期です」

#### 5. 多頭飼い向け一括管理
複数のペットの情報を1つの画面でまとめて確認できる。　✅

例：

**今日やること**
- ポチの薬
- ミケのトリミング予約
- ココのフード購入

#### 6. 家族共有機能
家族で以下の情報を共有できるようにする。

- 健康記録
- 通院履歴
- 今後の予定
- フードや用品の購入状況
- ペットごとの注意事項

#### 7. フード・用品の購入機能
フードやトイレ用品などをアプリ内から購入できるようにする。

将来的には、消費ペースから「そろそろフードがなくなりそうです」と通知し、そのまま購入できる仕組みを想定する。

ハッカソンでは、商品一覧や購入までの流れをデモ用として作成する程度でもよい。

#### 8. 病院・トリミングの検索・予約
近くの動物病院やトリミングサロンを検索し、そのまま予約できる機能。

実際の病院やトリミング店との連携は難しいため、ハッカソンでは架空の動物病院・トリミングサロンを用意し、検索・詳細表示・予約までの流れをデモとして実装する。

#### 9. ペットSNS・コミュニティ機能
ペットの写真や動画を投稿し、他の飼い主に見てもらったり、愛犬家・愛猫家同士で交流できる機能。

例：
- 写真・動画投稿
- いいね
- コメント
- 犬種・猫種ごとの交流
- 他の飼い主のペットを見る

### 収益モデル

#### 1. 月額サブスク
より便利な管理機能を有料で提供する。

例：
- 複数ペットの管理
- 家族共有
- フード消費時期の予測
- 高度なリマインド
- 長期間の健康履歴管理

#### 2. 商品販売手数料
アプリ経由でフードやペット用品が購入された場合に、販売手数料を得る。

#### 3. 予約手数料
アプリ経由で動物病院やトリミングサロンの予約が成立した場合に、予約手数料を得る。
